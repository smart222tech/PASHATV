Goal: attract an international audience for lawful Google TV / Android TV setup and troubleshooting help. No paid ads, no bulk spam, no claims of guaranteed ranking.

## Weekly cadence

- YouTube: 1 useful tutorial video + 2 Shorts
- Instagram/Facebook: 2 Reels + 1 carousel, scheduled using official tools where available
- Pinterest: 2 original vertical pins linking to the relevant guide
- Search/SEO: improve one guide each week based on actual search data

Repurpose one verified topic into multiple formats; do not post identical copy everywhere.

## Publishing checklist

Before each post:
1. Confirm every technical claim against the current device/app version.
2. Confirm the destination URL opens and the target page is public.
3. Use only authorized apps, playlists, and content sources.
4. Add a channel-specific UTM tag when analytics is configured.
5. Use platform-native scheduling or an official supported integration.
6. Do not mass-post repetitive links, scrape users, or automate unsolicited DMs.

## Measurement

Review weekly:
- Search Console: impressions, clicks, queries, indexed URLs
- YouTube Studio: views, retention, clicks on available links
- Meta insights / Pinterest analytics: reach, saves, outbound clicks
- Website analytics: sessions and referral sources, if configured

Do not judge SEO in the first few days. Record a baseline and compare over several weeks.
