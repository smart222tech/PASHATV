4. Fire TV — установка и важные настройки

1. Как открыть параметры разработчика

  1. Открой настройки Fire TV (значок шестерёнки).
  2. Перейди в «Мой Fire TV» → «Информация».
  3. Выбери название устройства и несколько раз нажми OK, пока не появится сообщение о параметрах разработчика.

2. Разрешение установки из неизвестных источников

  1. Открой «Настройки» → «Мой Fire TV» → «Параметры разработчика».
  2. Выбери «Установка неизвестных приложений».
  3. Разреши установку только для того приложения, через которое устанавливаешь файлы, например Downloader.
Важно для безопасности: Разрешай установку только для приложений и файлов из источников, которым доверяешь. Не нужно включать разрешение для всех приложений подряд. После завершения установки можно снова отключить разрешение для Downloader.

3. После установки

Открой установленное приложение. Проверь, предлагает ли оно обновление. В исходной публикации отмечено, что без обновления некоторые приложения могут работать неправильно. Обновляй только из источника, которому доверяешь.
